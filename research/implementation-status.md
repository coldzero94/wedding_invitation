## 완료한 구현

Astro 7 정적 사이트를 만들었다. 모바일에서는 표지·사진 이야기·SNS 피드·예식 안내가 세로로 이어지고, 1000px 이상에서는 표지와 본문을 나란히 표시한다. 높이가 짧은 PC에서는 표지 고정을 풀어 내용을 가리지 않는다.

사진 모달, 방향키와 스와이프, 닫기와 포커스 복귀, 날짜 기반 달력·카운트다운, ICS 일정 다운로드, 연락처 모달, 선택적인 계좌·주소 복사, 시스템 공유와 수동 복사 폴백을 구현했다. 하트는 해당 브라우저에만 보관한다.

후속 보완으로 이야기 앨범과 전체 사진을 분리했다. 앨범은 사진 ID 목록으로 여러 장을 묶고, 본문 대표 사진은 별도로 선택한다. 사진 수가 늘어도 앨범 카드와 본문 대표 컷 수는 유지된다. 잘못된 사진 ID·중복 ID·빈 앨범은 빌드 오류로 알려준다. 표지 사진의 설명과 자르기 위치도 독립적으로 설정한다.

표지에 예식 장소와 상세 안내 링크를 추가했다. 사진·연락처·복사 창은 브라우저 뒤로가기로 닫고 앞으로가기로 다시 열 수 있다. 사진 넘기기는 방문 기록을 늘리지 않으며, 닫기·Escape도 같은 기록을 정리한다. 뒤로가기 후 원래 위치와 버튼 초점을 복원한다.

추가 개발로 발송 모드의 빈 연락처·계좌 숨김, 갤러리 로딩 실패 안내·재시도, 예식 설정 검사, 발송용 `build:release` 명령을 구현했다. 발송용 빌드에는 실제 HTTPS 도메인·상세 주소·샘플 해제가 필요하다. 일정 파일에는 홀·층 등 장소 상세 정보도 포함하고 카운트다운은 설정한 시간대를 따른다.

GitHub Pages 수동 배포 워크플로 파일을 작성했다. 저장소가 연결되면 Pages의 도메인·경로를 읽어 타입 검사·발송용 빌드 후 배포하도록 구성했다. YAML 구조만 로컬에서 확인했으며 GitHub에서 실행하거나 사이트를 공개한 것은 아니다.

사진은 내장 이미지 생성 도구로 만든 가상 커플 이미지 세 장이다. 생성 프롬프트는 [자산 기록](mockups/site-assets.md)에 보관했다. 빌드 시 WebP와 OG용 JPEG로 변환한다. 폰트 파일과 라이선스는 사이트에 함께 배포된다.

## 확인한 범위

- Astro 정적 빌드와 타입 검사.
- 기존 Chrome 검사에 이야기 앨범·전체 갤러리 분리, 복수 사진 앨범의 순서와 이야기, 뒤로가기·앞으로가기·위치·초점·방문 기록 복원 검사를 추가했다.
- 데이터 검사는 30장으로 사진 순서를 바꿔도 선택한 앨범과 대표 컷이 유지되는지, 잘못된 설정이 오류로 드러나는지 확인한다. 실제 사진 30장의 모바일 성능을 측정한 것은 아니다.
- 루트 경로 검사에서 발견한 뒤로가기 초점 문제를 수정하고 해당 검사를 통과했다. 이후 GitHub Pages 형식의 `/wedding_invitation/` 경로에서 전체 16개 검사를 통과했다.
- 최신 후속 구현에서는 23개 검사(브라우저 17개, 데이터·설정 6개)를 모두 통과했다. 사진 요청 실패 후 재시도, 잘못된 예식 날짜·배포 주소 거부, 가상 데이터를 넣은 발송 모드 검사를 포함한다.
- 발송 모드 검사는 프로젝트를 임시 폴더에 복사해 별도 경로로 빌드한다. 연락처·계좌를 생략한 경우와 입력한 경우의 전화·문자·지도 링크, 주소·계좌 복사, 갤러리 실행을 확인했다. 실제 번호로 연락하거나 외부 지도를 실행하지 않는다. 임시 폴더는 검사 후 삭제했다.
- 폭 320·360·390·430·768·1024·1440px에서 가로 넘침 확인.
- 320px 화면에서 글자를 두 배로 확대할 때 제목·메뉴·날짜가 줄바꿈하도록 수정했다.
- QR 스크립트의 임시 SVG·1024px PNG 생성, 로컬 주소 거부를 확인했다. 검사 파일은 삭제했으며 실제 배포용 QR은 아직 없다.

## 실사용 전에 남은 정보

- 실제 이름·사진·날짜·예식장 주소·연락처·선택적인 계좌 정보 입력.
- 실제 GitHub 저장소와 Pages URL 확정, 배포 설정.
- 해당 주소를 담은 QR 생성과 실제 인쇄물 스캔.
- iPhone Safari·Android·카카오톡 인앱 브라우저 실기기 확인.
- 카카오 전용 공유 버튼이 필요하면 JavaScript 앱 키와 도메인 등록.

현재 정보와 사진은 가상 예시이며 상세 주소·전화·계좌는 비어 있다. Git 초기화나 저장소 생성은 하지 않았다. 무료 정적 사이트이므로 Git 초기화는 제작에 필수적이지 않으며, 버전 관리와 GitHub 배포를 시작할 때 진행하면 된다.
