## 조사한 모바일 청첩장 프로젝트

### `sooftware/our-wedding-invitation`

- FastAPI 백엔드
- AI 챗봇
- 방명록과 RSVP
- 하객 사진 업로드 및 S3
- PostgreSQL/SQLite와 관리자 페이지
- Railway 배포
- 라이선스: CC BY-NC-SA

기능은 풍부하지만 현재 요구에는 과하다. 오프닝 애니메이션과 콘텐츠 구성만 참고하고 백엔드 구조는 사용하지 않는다. 코드를 사용할 경우 출처 표기와 동일 라이선스 조건을 확인해야 한다.

- [프로젝트 저장소](https://github.com/sooftware/our-wedding-invitation)

### `juhonamnam/wedding-invitation`

- React/Vite 기반 반응형 사이트
- 이미지 갤러리
- 네이버 지도
- 카카오톡 공유
- 방명록과 RSVP는 선택 사항
- `VITE_STATIC_ONLY=true` 설정으로 서버 없이 운영 가능
- GitHub Pages 배포 지원
- 라이선스: MIT

두 예시 중 현재 목표에 더 가깝다. 한국형 정보 구조와 공유·지도 흐름을 참고하고, 화면 디자인은 새로 만든다.

- [프로젝트 저장소](https://github.com/juhonamnam/wedding-invitation)
- [공개 데모](https://juhonamnam.github.io/wedding-invitation/)
