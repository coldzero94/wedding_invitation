## 접근성과 모바일 사용성

화려한 연출보다 청첩장의 핵심 정보에 빠르게 도달하는 것이 우선이다.

- 첫 오프닝에는 `건너뛰기`를 제공한다.
- 오프닝을 본 뒤에는 같은 탭에서 다시 강제로 재생하지 않는다.
- `prefers-reduced-motion` 사용자는 패럴랙스, 흔들림, 자동 이동을 끈다.
- 갤러리 스와이프에는 이전·다음 버튼도 제공한다.
- 터치 버튼은 가능하면 44×44 CSS px 이상으로 만든다.
- 사진만으로 날짜나 위치를 전달하지 않고 실제 텍스트로도 제공한다.
- 장식용 사진은 `alt=""`, 의미 있는 사진은 짧은 대체 텍스트를 제공한다.
- 계좌번호 복사 결과는 화면과 스크린 리더에 모두 알린다.
- 키보드로 갤러리를 열고 닫고 이동할 수 있게 한다.
- 화면 전체를 강제로 한 장씩 넘기는 scroll hijacking은 사용하지 않는다.

WCAG 2.2의 최소 터치 대상은 24×24 CSS px이며, 44×44 CSS px은 더 편안한 목표다. 사진 중심 사이트에서도 장식 이미지와 정보 이미지를 구분해 대체 텍스트를 정해야 한다.

- [WCAG 2.2](https://www.w3.org/TR/wcag/)
- [W3C 장식 이미지 처리](https://www.w3.org/WAI/tutorials/images/decorative/)
- [W3C 이미지 대체 텍스트 지침](https://www.w3.org/WAI/tutorials/images/tips/)

## 실제 검증 환경

출시 전 아래 환경을 모두 확인한다.

| 환경 | 확인 내용 |
| --- | --- |
| iPhone Safari | 레이아웃, 음악 시작, 공유, 전화·문자 링크 |
| iPhone 카카오톡 인앱 브라우저 | 초기 로딩, 카카오 공유 복귀, 지도 이동 |
| Android Chrome | 갤러리 스와이프, 공유, 복사 |
| Android 카카오톡 인앱 브라우저 | SDK, 지도 앱 전환, 뒤로 가기 |
| Samsung Internet | 레이아웃과 시스템 공유 폴백 |
| PC Chrome/Safari/Edge | 넓은 화면 레이아웃과 키보드 조작 |
| 느린 모바일 네트워크 | 첫 사진과 본문이 빠르게 표시되는지 |
| 실제 인쇄 QR | 25~30mm 크기, 무광/유광 종이, 밝고 어두운 조명 |

기능 테스트 외에 카카오톡 채팅방에 URL을 직접 붙여 넣어 OG 이미지·제목·설명을 확인한다. QR은 화면 속 이미지로만 검사하지 않고 최종 인쇄 시안으로 다시 스캔한다.

## 개인정보와 운영상 주의점

- 공개 저장소에서는 소스·웹용 사진·Git 기록도 누구나 볼 수 있다. 사이트에 공개할 정보만 넣고, 스튜디오 원본·미사용 사진·비밀 키는 저장소에 넣지 않는다. 비공개 저장소로 바꾸더라도 배포된 사이트의 정보는 별도로 공개된다.
- 검색 결과 노출을 줄이기 위해 `robots`의 `noindex, nofollow`를 설정한다.
- 카카오톡 등으로 공유된 URL은 다른 사람에게 전달될 수 있다고 가정한다.
- 계좌번호와 연락처는 초기 화면에 노출하지 않고 사용자가 펼쳤을 때 표시한다.
- 예식 종료 후에는 전화번호와 계좌번호를 제거한 보관용 버전을 다시 배포한다. 재배포만으로 공개 Git 기록이나 이미 복제된 자료까지 삭제되는 것은 아니다.
- 사용 권한이 있는 사진, 음악, 폰트만 배포한다.

## 구현 원칙

- GitHub Pages에 정적 HTML·CSS·JavaScript·사진만 배포한다.
- GitHub Actions는 공개 저장소에서 정적 빌드·배포에 사용하고 유료 실행 환경은 사용하지 않는다.
- 카카오톡 공유의 유료 API 설정을 활성화하지 않는다.
- 지도는 SDK 대신 HTTPS 바로가기를 사용한다.
- 배경 음악은 기본 범위에서 제외하고, 권리가 확인된 경우에만 추가한다.
- 웹용 사진은 변환하며 모든 위치·카메라 메타데이터를 제거한다.
- 폰트는 재배포가 허용된 WOFF2만 자체 호스팅한다.
- 외부 QR 생성·리디렉션 서비스를 사용하지 않는다.
- 오프닝은 건너뛸 수 있고 모션 감소 설정을 존중한다.
- 예식 종료 후 개인정보를 제거한 보관용 버전으로 교체한다.
